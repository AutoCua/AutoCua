<google_sheets>
Writing a table into Google Sheets, reading cells and changing them, all with `run_script`; checked on 2026-10-08. The grid is drawn on a canvas: cells have no DOM of their own, the clipboard is out of a script's reach (the guardrails refuse navigator.clipboard and execCommand), and `input` types into one cell only. What works is a paste EVENT of your own, carrying the whole table, into the cell the sheet has selected: one call, the whole table, formatted.

<the_paste>
1. Select the top-left cell first: click it, or jump by name (<moving>). The paste fills down and right from it and overwrites what is there.
2. The script builds a DataTransfer, sets text/html (a <table>) and text/plain (the same cells as TSV: tabs between cells, newlines between rows), and dispatches a ClipboardEvent "paste" on document.activeElement, the hidden cell input (DIV.cell-input) that holds focus while a cell is selected. Sheets handles it as a real paste: dispatchEvent returns false, and the table lands in one go (18 rows by 11 columns in 0.2 s).
3. The look rides in text/html as inline styles on the cells: font-weight, font-style, font-size, color, background, text-align. A colspan merges cells (a title across the table). Values written as "$6,780", "30.2%" or "3,700" become numbers in that format, right-aligned, and the status bar sums them.
4. text/plain alone pastes the values without a look. Set both: text/plain is what Sheets falls back to.
5. Nothing in the paste sets a column's width: set it after the paste (<widths>). Row height follows the font and wrapped text on its own.
6. One call: build the HTML from an array of rows inside the script (example 3), never a call per row or per cell.
</the_paste>

<moving>
1. By name: the name box (#t-name-box) is a plain input and takes a value set by script with an Enter key event. A cell ("A21") moves there; a range ("A1:K18") selects it for a `delete` or a format shortcut.
    run_script {"id": 1, "type": "action", "value": "const nb = document.getElementById('t-name-box'); nb.focus(); nb.value = 'A21'; nb.dispatchEvent(new Event('input', {bubbles: true})); nb.dispatchEvent(new KeyboardEvent('keydown', {key: 'Enter', keyCode: 13, bubbles: true})); return nb.value"}
2. By key (`keyboard`): the arrows move one cell, "cmd+home" goes to A1, "cmd+a" selects the data block and a second "cmd+a" the whole sheet.
3. Clear a range: select it, then "delete" takes the values and "cmd+\" the formatting.
</moving>

<reading>
1. One cell: jump to it by name and read the formula bar, in one call. The formula bar holds the cell's own content: a number without its format (8831 for a cell drawn as $8,831), a formula as written (=C4*2).
    run_script {"id": 1, "type": "action", "value": "const nb = document.getElementById('t-name-box'); nb.focus(); nb.value = 'B8'; nb.dispatchEvent(new Event('input', {bubbles: true})); nb.dispatchEvent(new KeyboardEvent('keydown', {key: 'Enter', keyCode: 13, bubbles: true})); return {cell: document.querySelector('#t-formula-bar-input').innerText.trim()}"}
    Back: {"cell": "32.3%"}
2. A range, or a cell as it is drawn: select it, then dispatch a ClipboardEvent "copy" with a DataTransfer of your own. Sheets fills it with the selection: text/plain as TSV of the values as drawn ($8,831, 30.20%), text/html as a table. The clipboard is not touched; the DataTransfer is yours to read.
    run_script {"id": 1, "type": "action", "value": "const nb = document.getElementById('t-name-box'); nb.focus(); nb.value = 'A4:D5'; nb.dispatchEvent(new Event('input', {bubbles: true})); nb.dispatchEvent(new KeyboardEvent('keydown', {key: 'Enter', keyCode: 13, bubbles: true})); const dt = new DataTransfer(); const handled = !document.activeElement.dispatchEvent(new ClipboardEvent('copy', {clipboardData: dt, bubbles: true, cancelable: true})); return {handled, text: dt.getData('text/plain')}"}
    Back: {"handled": true, "text": "Revenue ($M)\t$6,780\t$8,831\t$11,693\nYoY Revenue Growth\t-\t30.20%\t32.40%"}
3. A formula's result is only drawn: the formula bar gives the formula, the copy event gives the value ("$17,800" for =C4*2).
</reading>

<widths>
1. Sheets' own fit (a double-click on the header border, or Resize column > Fit to data) takes the WIDEST cell of the column, merged titles included: with the title merged across the table, column A came out 1110 px. Use it only on columns without merged cells (the number columns).
2. The label column fits when it is as wide as the longest text that STARTS in it: its plain cells and its left-aligned merged section headings, centered or right-aligned merged titles skipped, plus 8 px (Sheets' own padding). The call below reads the column by a copy event (each cell with its font), measures the texts, and types the width into the Resize column dialog from the header's context menu. One call per column (`col`, `rows`); it gave 489 px where the sheet's fit by hand gave 487.
    run_script {"id": 1, "type": "action", "value": "const col = 'A', rows = 'A1:A60'; const nb = document.getElementById('t-name-box'); const go = (r) => { nb.focus(); nb.value = r; nb.dispatchEvent(new Event('input', {bubbles: true})); nb.dispatchEvent(new KeyboardEvent('keydown', {key: 'Enter', keyCode: 13, bubbles: true})); }; const sleep = (ms) => new Promise((r) => setTimeout(r, ms)); const until = async (f) => { for (let i = 0; i < 20; i++) { const e = f(); if (e) return e; await sleep(100); } return null; }; const ev = (el, t, x, y, b = 0) => el.dispatchEvent(new MouseEvent(t, {bubbles: true, cancelable: true, clientX: x, clientY: y, button: b, buttons: t === 'mousedown' ? (b === 2 ? 2 : 1) : 0, view: window})); const click = (el) => { const r = el.getBoundingClientRect(), x = r.x + r.width / 2, y = r.y + r.height / 2; ev(el, 'mousedown', x, y); ev(el, 'mouseup', x, y); ev(el, 'click', x, y); };\ngo(rows); const dt = new DataTransfer(); document.activeElement.dispatchEvent(new ClipboardEvent('copy', {clipboardData: dt, bubbles: true, cancelable: true}));\nconst ctx = document.createElement('canvas').getContext('2d'); let best = 0, text = '', plain = 0, row = 0;\nfor (const m of dt.getData('text/html').matchAll(/<tr[^>]*>\\s*<t[dh]([^>]*)>([\\s\\S]*?)<\\/t[dh]>/gi)) { row++; const st = (m[1].match(/style=\"([^\"]*)\"/) || [])[1] || ''; const p = (k, d) => ((st.match(new RegExp(k + ':\\\\s*([^;]+)')) || [])[1] || d).trim(); const merged = /colspan=/.test(m[1]); if (merged && p('text-align', 'left') !== 'left') continue; if (!merged && !plain) plain = row; const t = m[2].replace(/<[^>]+>/g, '').replace(/&amp;/g, '&').replace(/&nbsp;/g, ' ').trim(); if (!t) continue; const fs = p('font-size', '10pt'); ctx.font = `${p('font-weight', 'normal')} ${fs.endsWith('px') ? parseFloat(fs) : parseFloat(fs) * 4 / 3}px ${p('font-family', 'Arial')}`; const w = ctx.measureText(t).width; if (w > best) { best = w; text = t; } }\nconst px = Math.ceil(best) + 8; go(col + plain); const a = document.querySelector('.active-cell-border').getBoundingClientRect(), h = document.getElementById('0-column-headers-background').getBoundingClientRect(), x = a.x + 15, y = h.y + h.height / 2, hd = document.elementFromPoint(x, y);\nev(hd, 'mousedown', x, y, 2); ev(hd, 'mouseup', x, y, 2); ev(hd, 'contextmenu', x, y, 2);\nclick(await until(() => [...document.querySelectorAll('.goog-menuitem')].find((e) => e.offsetParent && /^resize column/i.test(e.innerText))));\nconst dlg = await until(() => [...document.querySelectorAll('.modal-dialog')].find((e) => e.offsetParent && /resize column/i.test(e.innerText)));\nconst inp = dlg.querySelector('input:not([type=radio])'); inp.value = String(px); inp.dispatchEvent(new Event('input', {bubbles: true}));\nclick([...dlg.querySelectorAll('button')].find((e) => /^ok$/i.test(e.innerText.trim()))); await sleep(300); go(col + plain);\nreturn {col, px, text, width: Math.round(document.querySelector('.active-cell-border').getBoundingClientRect().width)};"}
    Back: {"col": "A", "px": 489, "text": "1. INCOME STATEMENT HIGHLIGHTS ($ in millions except per share)", "width": 491}
3. Rows need nothing: their height follows the font and wrapped text. The row header has the same menu (Resize row) when one must change.
</widths>
